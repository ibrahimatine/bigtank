### 2. Menu de statut admin (mobile) — CORRIGE
- **Probleme** : le dropdown de changement de statut debordait sur mobile, invisible ou inaccessible
- **Cause** : utilisation de `position: fixed` avec calcul de position via `getBoundingClientRect()` qui ne fonctionnait pas bien sur mobile
- **Solution** : remplacement par un **bottom sheet** (panneau modal qui monte du bas de l'ecran)
  - Fonctionne sur toutes les tailles d'ecran
  - Animation `slide-up` ajoutee dans `globals.css`
  - Fond semi-transparent avec fermeture au clic exterieur
- **Fichier** : `apps/web/src/components/admin/listing-status-action.tsx`

### 3. Sync Meilisearch admin → recherche — CORRIGE
- **Probleme** : quand l'admin mettait une annonce en "Disponible", elle n'apparaissait pas dans Explorer ni a l'accueil
- **Cause** : Railway executait une **ancienne version du code** — `railway redeploy` ne prenait pas le dernier code git
- **Solution** :
  - Utilisation de `railway up` pour pousser le code local directement sur Railway
  - Verification via les logs : "Meilisearch connection restored" (nouveau message) au lieu de "Meilisearch connecte" (ancien)
  - Le code backend etait deja correct (`indexListing` appele dans `updateListingStatus`)

### 4. Bouton Reindexer — NOUVEAU
